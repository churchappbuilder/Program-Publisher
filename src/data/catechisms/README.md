# Catechism data

The four JSON files here (`wsc`, `wlc`, `heidelberg`, `baptist-catechism`) were obtained from
[reformededucation.org](https://reformededucation.org/catechisms.html), which states that these
documents and their King James Version Scripture proofs are in the public domain.
`_index-source.json` is that site's description of each document (source, translation, notes), kept for provenance.

| File | Document | Source note from the site |
|---|---|---|
| `wsc.json` | Westminster Shorter Catechism (1648), 107 questions | Public domain; KJV proofs |
| `wlc.json` | Westminster Larger Catechism, 196 questions | Public domain; KJV proofs |
| `heidelberg.json` | Heidelberg Catechism (1563), 129 questions | English translation as published by apuritansmind.com; **not yet proofread against a printed edition**; some questions word differently from other editions |
| `baptist-catechism.json` | Baptist Catechism (Keach's, 1693), 114 questions | 1695 fifth edition, spelling lightly modernized; **not yet proofread against a scanned original** |

Churches should compare these with the edition they use and, where they differ, save their own wording in the
app's Text library. The app shows these cautions next to the catechism picker.
